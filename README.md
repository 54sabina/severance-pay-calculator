# 資遣不求人（Severance Pay Calculator）

被資遣時試算公司應付的款項：資遣費、預告工資、特休未休工資（以小時計），以及謀職假天數。

- 單一檔案 `index.html`，不需要建置或安裝套件，直接用瀏覽器開啟即可。
- 可直接部署到 GitHub Pages（Settings → Pages → Deploy from a branch → `main` / root）。

## 計算依據

| 項目 | 規則 | 法條 |
|---|---|---|
| 資遣費（新制） | 每滿 1 年給 0.5 個月平均工資，未滿 1 年按比例，最高 6 個月 | 勞工退休金條例 §12 |
| 資遣費（舊制） | 每滿 1 年給 1 個月平均工資，未滿 1 個月以 1 個月計 | 勞基法 §17 |
| 預告期間 | 3 個月～1 年：10 天；1～3 年：20 天；3 年以上：30 天 | 勞基法 §16 |
| 預告工資 | 不足天數 × 一日工資（月薪 ÷ 30，低於平均工資時以平均工資計） | 勞基法 §16 III |
| 謀職假 | 預告期間每 7 日可請 2 日；剩餘不足 7 日仍可請 2 日，只剩 1 日請 1 日 | 勞基法 §16 II |
| 特休 | 週年制天數 × 8 小時；未休時數 × (月薪 ÷ 30 ÷ 8) | 勞基法 §38 |

## 驗算案例（勞動部與法院範例）

- 平均工資 30,000、年資 3 年 6 個月 15 天 → 新制資遣費 53,125 元；舊制 107,500 元
- 7/13 通知、7/30 最後工作日 → 預告 17 天，謀職假最多 6 天
- 月薪 27,470、未休特休 7 天 → 6,410 元

> 本工具僅供試算參考，不構成法律意見。
